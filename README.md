# 🫁 Smart Prediction – Maladies Radiothorax (Chest X-Ray AI System)

## 📌 Description
Le **Smart Prediction – Maladies Radiothorax** est un projet d’intelligence artificielle basé sur l’analyse d’images médicales (radiographies thoraciques).

Le système utilise des techniques de **deep learning et computer vision** pour détecter automatiquement des anomalies pulmonaires et aider au diagnostic des maladies respiratoires.

Ce projet s’inscrit dans le domaine de la **HealthTech et de l’IA appliquée à l’imagerie médicale**.

---

## 🎯 Objectifs du projet

- Détecter automatiquement des maladies thoraciques à partir de radiographies
- Appliquer le deep learning à l’imagerie médicale
- Améliorer la détection précoce des maladies pulmonaires
- Créer un système d’aide au diagnostic médical
- Expérimenter la vision par ordinateur en santé

---

## ⚙️ Fonctionnalités

- 🫁 Analyse d’images de radiographies thoraciques
- 🤖 Classification des images (sain / malade ou multi-classes selon modèle)
- 🧠 Utilisation de modèles de deep learning (CNN)
- 📊 Prétraitement des images médicales
- 🔍 Détection d’anomalies pulmonaires
- 📈 Évaluation des performances du modèle

---

## 🧠 Technologies utilisées

- Python
- TensorFlow / Keras (ou PyTorch selon implémentation)
- OpenCV
- NumPy
- Matplotlib
- Deep Learning (CNN)
- Jupyter Notebook

---

## 🏗️ Pipeline du projet

- Collecte des images de radiographies thoraciques
- Prétraitement des images (normalisation, redimensionnement)
- Augmentation des données (data augmentation)
- Construction du modèle CNN
- Entraînement du modèle sur dataset médical
- Évaluation des performances
- Prédiction sur nouvelles images
